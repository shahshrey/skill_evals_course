What every good eval setup agrees on

Six rules that matter more than any one eval

1

Test the description before the body. A skill that does not load cannot help.

2

Grade with code where you can, and prove the grader on a known-good and a known-bad answer.

3

Pair the with and without runs, hold everything else fixed, report the delta with an interval.

4

Grade the end state and the tool log, not the transcript's narration.

5

Keep the skill files physically absent from the baseline workspace.

6

Save every raw row. Analysis should never need a new run.

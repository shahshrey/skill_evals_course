3. Offline routing

Does the description use the words users type, without colliding with neighbouring skills?

How it works

  • Put every installed skill's description in a catalog
  • Rank the catalog against sample prompts with plain text similarity
  • Positives must rank your skill first; negatives must rank the rightful owner above it; no two descriptions may be near-duplicates

Watch out for

  • This is not how the real harness routes, so a pass here is not proof of triggering
  • When a positive fails, fix the description, not the prompt

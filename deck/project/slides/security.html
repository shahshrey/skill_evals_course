2. Security scan

Does the skill ask the agent to do something hostile?

How it works

  • Match every file against known-bad patterns: instruction overrides, hidden text, credential paths, data sent to remote hosts, piped installs
  • Score by severity, with repeat hits on the same rule counting less each time
  • Verdict bands: safe, review first, do not install

Watch out for

  • Static scans have false positives; a skill about SSH will mention ~/.ssh
  • Never run the skill to test it. Read it.

Skill evals, the eleven types

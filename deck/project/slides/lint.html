1. Structural lint

Is this SKILL.md well-formed enough for a harness to load it at all?

How it works

  • Parse the frontmatter and check the spec: name format, name matches the folder, description length
  • Look for a trigger phrase in the description ("use when ...")
  • Check the body: unclosed code fences, referenced files that do not exist

Watch out for

  • A name that does not match its folder never loads, and nothing tells you
  • Lint proves the file is loadable, not that it is good

10. Regression check

Did anything get worse since the last run you trusted?

How it works

  • Save a baseline: the key metrics plus a hash of the skill's files
  • On every later run compare each metric against the baseline with a tolerance
  • A drop after the skill changed is expected churn; a drop with no change is drift in the model or harness

Watch out for

  • Without the content hash you cannot tell your edit from the world moving under you
  • Skills rot; a check nobody runs catches nothing

Starting point

A skill is instructions loaded on demand

What that means

  • A folder with a SKILL.md: a name, a description, and a procedure
  • The harness (Claude Code and friends) reads the description to decide when to load it
  • The model never sees the body until the skill is loaded

Why it needs evals

  • A skill that never loads fails silently: no error, no log line
  • A skill that loads can still be ignored, half-followed, or overridden
  • Most software engineering skills measured so far add little or nothing

Skill evals, the eleven types

Two failure modes to keep in mind for the whole deck: not loading, and loading but not helping.

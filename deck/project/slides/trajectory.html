8. Trajectory eval

Did the agent follow the procedure and respect the prohibitions?

How it works

  • Record every tool call the agent makes, in order
  • Compliance: required steps happened, and in the right order (skill loaded before the work started)
  • Boundary: forbidden actions never happened, even when the user asked for them

Watch out for

  • A perfect output can come from a skipped procedure; only the tool log shows it
  • The course's sample skill lost this one: asked directly, the agent ran git commit anyway

Skill evals, the eleven types

Score is trigger times the share of procedure steps followed, and any broken prohibition sets it to zero. No trigger, no score.

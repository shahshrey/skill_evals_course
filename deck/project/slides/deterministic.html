5. Deterministic grading

Does the output follow the rules we can check with code?

How it works

  • Turn every checkable rule into a function: regex for the format, a length limit, a required line
  • Prove the grader first: a hand-written perfect answer must pass, a wrong one must fail
  • Report pass rate per rule, not one blended score

Watch out for

  • A grader that rejects the oracle measures the grader, not the skill
  • Rules a regex cannot express go to the judge, not into a looser regex
